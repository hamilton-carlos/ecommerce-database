# Banco de Dados de E-commerce

Estrutura relacional desenvolvida em PostgreSQL para simular a operação backend de uma loja virtual. 

O projeto cobre desde o gerenciamento de estoque e catálogo até a persistência de vendas e fluxo de pagamentos.

## Entidades Mapeadas

- Clientes
- Categorias
- Produtos
- Pedidos e Itens do Pedido
- Pagamentos

## Tecnologias

- PostgreSQL
- SQL

## Aplicação Prática

O script aborda os seguintes pontos no banco de dados:

- Modelagem e normalização de dados
- Configuração de chaves (PKs e FKs) e integridade referencial
- Consultas complexas com JOINs e funções de agregação
- Criação de Views para relatórios e Índices para otimização de busca
